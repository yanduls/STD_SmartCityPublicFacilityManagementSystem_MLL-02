# Smart City Public Facility Management System (Multi Linked List)

Aplikasi berbasis konsol (C++) untuk mengelola data fasilitas publik dan petugas lapangan menggunakan implementasi struktur data **Multi Linked List (MLL)**. Proyek ini dibuat untuk memenuhi Tugas Besar mata kuliah Struktur Data.

## Struktur Data
Program ini mengimplementasikan Multi Linked List dengan relasi **Many-to-Many**:
- **Parent List (`fasilitas`)**: Menyimpan data fasilitas publik kota.
- **Child List (`petugas`)**: Menyimpan data petugas pengelola.
- **Relation List (`relasi`)**: Menghubungkan fasilitas dengan petugas yang bertugas.

## Fitur Utama
- Manajemen data Fasilitas (Tambah, Lihat, Cari, Hapus)
- Manajemen data Petugas (Tambah, Lihat, Cari, Hapus)
- Pengelolaan Relasi penugasan antara Petugas dan Fasilitas
- Menampilkan daftar petugas pada fasilitas tertentu maupun sebaliknya
